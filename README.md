# Circle - backend

Circle is an application which helps groups of people schedule casual events (things that don't need a *ton* of planning, but might benefit from a bit of organization, ala playing pickup basketball, getting boba, or studying together.)  
This repository hosts the server-side code which makes the application possible. It is written using Python, primarily relying on the FastAPI and SQLModel libraries.  
Generative AT (Cursor) was used to generate a small fraction of the code in this repository. Specifically, I used Cursor to write some of the class definitions in the schema folder.  
The API docs can be found at [this URL](http://170.9.13.43:8000/docs).
